Narrow-terminal usage bars: real TUI paint, captured through a pty.

How: each frame is TUI.start() itself (alternate screen, raw stdin, the real
_paint to process.stdout) run under `script -q -e -c "stty cols W rows 24; node live.mjs"`,
against an in-memory fleet (test-helpers/tui-frame.js fleetAccounts) with a
temporary HOME and no config file, server or token. The last painted frame
before stop() is extracted from the typescript and its ANSI codes stripped;
"|" marks column 0 and the column past the last. The widest line of every
frame is exactly the terminal width.

Below 70 columns each account folds into a heading and one line per quota
bar, every bar ending two columns before the right edge. 80 columns is the
unchanged wide layout, for comparison.
